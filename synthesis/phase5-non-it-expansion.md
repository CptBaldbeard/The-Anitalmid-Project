# Non-IT Career Expansion — Convergence Analysis

> **Purpose**: Extend the Anitalmid Project beyond IT roles, using the
> six-framework profile (Birkman + MBTI + Enneagram + DISC + Big Five +
> Holland) to identify non-IT careers with structural aptitude support.

## Methodology

The IAR Holland Code (Investigative-Artistic-Realistic) is the primary engine
for non-IT career discovery because O*NET assigns RIASEC codes to every U.S.
occupation. Careers with IAR, I-A-R, A-I-R, or A-R-I codes are structurally
compatible. Careers with E (Enterprising) or S (Social) as primary codes are
structurally contraindicated.

Each non-IT career is evaluated across four dimensions:
1. **Holland Code match**: How closely does the career's O*NET RIASEC match IAR?
2. **Framework convergence**: Do MBTI (INTJ), Enneagram (5w6), DISC (CS), and
   Big Five (O-high/C-high/E-low) support the role?
3. **Birkman interest alignment**: Do Dan's interest scores (Scientific 92%,
   Literary 92%, Artistic 94%, Technical 82%) support the role?
4. **Career history evidence**: Does Dan have documented experience that
   supports this path?

## Key Finding

The non-IT expansion reveals that Dan's STRONGEST aptitude signals (Scientific
92% + Literary 92% + Artistic 94%) converge on science communication and
technical writing MORE STRONGLY than they converge on any IT role. The IT
career recommendations are validated by CAREER EXPERIENCE (Dan has done them);
the non-IT recommendations are validated by APTITUDE SIGNALS (Dan would be
naturally good at them). This is a classic experience-vs-aptitude trade-off
that the resume pipeline must handle.

## Implication for Phase C Pipeline

The resume-to-top-6 pipeline must:
1. Weight EXPERIENCE higher for roles where the candidate has direct history
2. Weight APTITUDE higher for roles where the candidate has strong framework
   signals but no experience (career change recommendations)
3. Flag "experience-validated" vs. "aptitude-validated" matches distinctly
4. Include non-IT roles in the top-6 output, not just IT roles
