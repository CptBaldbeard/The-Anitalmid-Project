# Data Analyst / Research Analyst

## Role Overview

Data analysts collect, process, and analyze data to help organizations make
informed decisions. They use statistical methods, visualization tools, and
domain expertise to identify trends, build reports, and communicate insights
to stakeholders. At senior levels, this evolves into data science (predictive
modeling, machine learning) or analytics engineering (data pipeline design).

## Why This Matches Dan's Profile

Dan's profile has STRONG alignment with the analytical dimension but a key
tension on the quantitative dimension:

### Strong alignment
- **Scientific interest 92%** — hypothesis-driven analysis, the core data science mindset
- **Investigating strength (#1)** — the primary analyst behavior
- **Technical 82%** — tool competency (SQL, Python, BI platforms)
- **Ambiguity handling** — comfort with incomplete data and uncertainty
- **Structured thinking** — systematic analysis methodology
- **Written word strength** — communicating findings (the most undervalued analyst skill)

### Tension point
- **Numerical interest 17%** — the SECOND-LOWEST Birkman area. Data analysis

  numerical data), it suggests Dan would prefer QUALITATIVE ANALYSIS (pattern
  recognition, thematic coding, threat analysis) over QUANTITATIVE ANALYSIS
  (regression modeling, statistical testing, financial modeling).
