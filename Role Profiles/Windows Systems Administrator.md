# Windows Systems Administrator — Role Profile

## Overview

A Windows Systems Administrator manages and maintains Windows Server
infrastructure in an enterprise environment. This role bridges on-premises
Active Directory domains with cloud services (Azure/Microsoft 365) and is
responsible for system availability, security, and performance across hundreds
or thousands of endpoints.

> **Career Aptitude Match**: This role suits individuals with strong analytical
> and systematic thinking patterns — see [[Birkman Insights/Strengths]] and
> [[analyzer - yellow]] / [[thinker - blue]] color profiles. Prior roles in
> [[Career History/Information_Systems_Specialist]] or
> [[Career History/Technology_Solutions_Partner]] often map well to this path.

## Why This Role Matters

Windows Server runs a majority of enterprise back-office workloads globally.
Even as organizations move to the cloud, hybrid Windows infrastructure remains
critical — every Azure migration still needs someone who understands AD, GPOs,
and the Windows security model.
