# UX Designer / Creative Technologist

## Role Overview

UX (User Experience) designers create intuitive, effective digital experiences
by understanding user needs, designing interfaces, and testing solutions. The
role spans research (user interviews, usability testing), design (wireframes,
prototypes, visual design), and strategy (information architecture, design
systems). Creative technologists add a development layer — they prototype
interactive experiences with code.
