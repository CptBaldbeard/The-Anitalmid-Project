# anitalmid-holland-1: Dan maps to Holland Code IAR

**Source:** [[Frameworks/Birkman-to-Framework Crosswalk]] — Section: Crosswalk 5 — Holland Codes (RIASEC)

## The Claim

Dan Bechtel's Birkman profile maps to Holland Code **IAR** (Investigative-primary,
Artistic-secondary, Realistic-tertiary) with notably low Conventional, Enterprising,
and Social interests. This code is highly consistent (I-A-R are adjacent on the
RIASEC hexagon) and strongly differentiated (clear highs and lows), suggesting a
coherent vocational personality well-suited for technical-creative hybrid roles.

## Evidence

### I — Investigative (Dominant)
- Scientific interest 92% — direct I-domain alignment
- Technical interest 82% — I-R overlap
- Investigating strength (#1) — core I behavior
- Blue Interests: theoretical, abstract, future-oriented — I cognitive style
- Ambiguity handling — I comfort with complexity
- **O*NET matches**: Systems Analyst, Security Analyst, Researcher, Scientist

### A — Artistic (Strong Secondary)
- Artistic interest 94% — direct A-domain alignment
- Musical interest 97%, Literary interest 92% — additional A evidence
- Written word strength (#4) — A creative expression
- Visual appeal strength (#3) — A aesthetic orientation
- Blue Interests: creating new approaches, innovation — A creative drive
- **O*NET matches**: Technical Writer, UX Designer, Creative Technologist

### R — Realistic (Tertiary)
- Technical interest 82% — direct R-domain alignment
- Hands-on problem solving strength (#2) — core R behavior
- Endpoint management experience (career-4) — R hands-on technical work
- Backup/DR experience (career-2) — R systems work
- Getting things done strength — R practical orientation
- **O*NET matches**: Systems Administrator, Network Engineer, Field Technician

### C — Conventional (Very Low)
- Administrative interest 20% — second-lowest of all 10 Birkman areas
- C work involves data entry, record-keeping, clerical organization
- Contraindicated: accounting, bookkeeping, data entry, administrative support

### E — Enterprising (Very Low)
- Persuasive interest 32% — third-lowest
- Contraindicated: sales, management, entrepreneurship, politics

### S — Social (Very Low)
- Social Service interest 21% — third-lowest
- Selective sociability, introverted Usual Behavior
- Contraindicated: teaching, counseling, social work, nursing

## Confidence

**Rating:** medium
**Rationale:** Inferred from Birkman data, not from direct Holland assessment (SDS or Strong Interest Inventory). However, this is the CLOSEST direct mapping of any framework because Birkman's 10 interest areas directly correspond to Holland dimensions. The Birkman-to-Holland mapping has more face validity than the Birkman-to-MBTI or Birkman-to-Enneagram mappings. Confidence could be upgraded to HIGH if confirmed by a formal Holland assessment.

## Stakes

Holland Codes are THE career matching framework. O*NET provides RIASEC codes for
every occupation in the U.S. economy, making this the most ACTIONABLE framework
inference. The IAR code opens up career matching across the ENTIRE O*NET database,
not just IT roles. Key implications:

1. **IAR → IA careers**: Research scientist, systems analyst, data analyst,
   security analyst, technical writer — investigative + artistic blend.

2. **IAR → IR careers**: Systems administrator, network engineer, software
   developer, database administrator — investigative + realistic blend.

3. **IAR → AR careers**: UX designer, technical artist, creative technologist,
   science communicator — artistic + realistic blend.

4. **Contraindicated**: Sales (E), management (E), teaching (S), counseling (S),
   clerical work (C), accounting (C).

## Assessment

The Holland Code inference is the most directly usable of the five framework claims
because it connects to the O*NET occupational database. Every career in the U.S.
economy has a RIASEC profile, enabling systematic career matching. The IAR code
is also the best-validated inference because Birkman's interest scores (Scientific,
Artistic, Technical, etc.) are direct analogues of Holland dimensions, rather
than requiring the kind of inferential leap needed for MBTI or Enneagram mapping.

The IAR code should be the primary engine for Phase B (non-IT career expansion)
and Phase C (resume-to-top-6-positions pipeline). Any career with a RIASEC code
of IAR, I-A-R, I-R-A, or A-I-R is a structural match candidate.
