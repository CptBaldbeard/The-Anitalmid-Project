# anitalmid-fit-5: Documentation Engineering is a competency, not a standalone career

**Source:** [[Career History/Technical_Writer]] + [[Dan Bechtel Birkman Profile]]

## The Claim

Dan has exceptional documentation aptitude — Literary interest 92%, Strength #4 (written word), real technical writing experience (ISO 27001, SOC2), KB development experience (reduced ticket resolution time), and compliance documentation experience. This combination supports Documentation Engineer or Senior Technical Writer roles. However, the rest of Dan's profile (Technical interest 82%, Scientific interest 92%, security operations experience) suggests documentation should be a differentiating competency WITHIN technical roles, not a standalone career. The risk of a pure writing career is that it under-serves the technical and investigative drives.

## Evidence

### Documentation aptitude:
| Signal | Evidence |
|---|---|
| Literary interest 92% | Birkman quantitative score |
| Written word (Strength #4) | Explicit strength statement |
| Technical Writer role | ISO 27001, SOC2, data privacy frameworks |
| KB development | Reduced Help Desk ticket resolution time |
| Compliance documentation | CJIS audit support |

### Why NOT standalone:
| Signal | Implication |
|---|---|
| Technical interest 82% | Drawn to technology itself, not just writing about it |
| Scientific interest 92% | Drawn to investigation and analysis, not just documentation |
| Security operations experience | Active practitioner, not just documenter |
| Blue Interests (innovation) | Drawn to CREATING systems, not just describing them |

## Confidence

**Rating:** medium

**Rationale:** Documentation aptitude is very strong (would be very-high confidence for a pure writing role). The uncertainty is whether a pure documentation career satisfies the technical and investigative drives. The claim is that documentation is a superpower, not a career — this is an inferential claim about career satisfaction, not measurable aptitude.

## Assessment

Documentation is Dan's superpower — it differentiates him from 90% of IT professionals. The recommendation is to deploy this superpower WITHIN technical roles (SysAdmin who writes excellent runbooks, Security Engineer who produces clear incident reports, Cloud Administrator who documents architectures) rather than pursuing a standalone documentation career. A hybrid role — Systems Administrator with documentation/GRC responsibilities — would leverage the full profile.
