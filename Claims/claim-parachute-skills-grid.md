# anitalmid-parachute-1: D-T-P Skills Grid profile

**Source:** [[Parachute Flower Exercise - Dan Bechtel Profile]] — Petal 3: Skills

## The Claim

Dan's transferable skills, analyzed through Richard Bolles' Skills Grid taxonomy
(People / Data / Things), reveal a clear D-T-P hierarchy that is consistent
across psychometric data, career history, and framework triangulation.

## Confidence

**Rating:** high
**Rationale:** The D-T-P pattern is derived from three independent evidence layers
(Birkman strengths + interest scores + documented career achievements) and is
cross-validated by all six psychometric frameworks. It is not self-report — it is
assessment-verified and career-history-documented.

## Stakes

This claim defines the SKILL ARCHITECTURE that underpins all career recommendations.
If the D-T-P pattern is accurate:
- **Systems Administrator** fits perfectly (D-T dominant, P present but secondary)
- **Security Analyst** fits (D-dominant, analytical/investigative)
- **Management tracks** are contraindicated (P-weak, missing supervisory skills)
- **Sales/Consulting** are contraindicated (P-weak, missing persuasive skills)

## Assessment

The D-T-P profile is the single most actionable insight from the Parachute
integration. It provides a simple, memorable formula for evaluating career fits:
if a role is primarily about Data and Things, with People limited to written
and one-on-one modes, it fits. If a role requires verbal persuasion, group
facilitation, or people management as primary duties, it does not.
