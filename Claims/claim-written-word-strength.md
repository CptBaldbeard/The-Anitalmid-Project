# anitalmid-birkman-17: Written word strength supports documentation and technical writing

**Source:** [[Dan Bechtel Birkman Profile]] — Birkman Basics Report (G6HVDQ, 2025-09-05)

## The Claim

Dan's Strength #4 explicitly names working with the written word as a core aptitude, spanning documentation to marketing materials. This is the behavioral expression of Literary interest (92%) — not just liking ideas about writing, but actually producing written output. The strength is domain-agnostic: it applies equally to technical documentation, compliance writing, knowledge base articles, and procedural documentation.

## Evidence

- Strength #4: "You like working with the written word, which may involve anything from documentation to the production of marketing materials"
- Literary interest: 92% — the motivational foundation
- Technical Writer role (2024-2025): ISO 27001, SOC2, data privacy documentation
- KB development (2016-2018): reduced Help Desk ticket resolution time
- Security documentation (2022-Present): CJIS audit support

## Confidence
