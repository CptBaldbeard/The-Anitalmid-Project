# anitalmid-career-5: Identity and access management experience across four roles

**Source:** Career History — multiple roles, 2014-2025

## The Claim

Dan's career history shows a consistent, escalating IAM thread across four roles over 11 years. This is not isolated exposure — it is a career-long pattern that spans the full IAM lifecycle: physical access (ID cards), logical access (user provisioning), access governance (access reviews), and authentication security (MFA deployment).

## Evidence

### Chronological IAM experience:

**Vandal Card Specialist (2016-2018):**
- "Co-led campus ID card program, enhancing campus-wide security and optimizing access management"
- "Managed user account provisioning and access permissions for students, faculty, and staff"

**Telecommunications Coordinator (2014-2015):**
- "Managed user account administration and access permissions across telecommunications systems"

**Technology Solutions Partner (2021-2022):**
- "Administered endpoint devices and software for distributed campus workforce, maintaining security baselines" — implies access control

**Information Systems Specialist (2022-Present):**
- "Spearheaded Duo MFA deployment for 200 employees, strengthening identity security"
- "Managed user lifecycle operations including provisioning, access reviews, and deprovisioning across multiple systems"
- "Administered security policies and access controls, maintaining CJIS Level 4 compliance"

### IAM lifecycle coverage:
| Phase | Evidence |
|---|---|
| Provisioning | User account provisioning (Vandal Card, Telecom, ISS) |
| Authentication | Duo MFA deployment (ISS) |
| Authorization | Access permissions, security policies (multiple roles) |
| Governance | Access reviews (ISS) |
| Deprovisioning | User lifecycle deprovisioning (ISS) |

## Confidence

**Rating:** very-high

**Rationale:** Four-role pattern over 11 years. The IAM responsibilities escalate from campus-scale (Vandal Card) to enterprise MFA deployment (ISS). Full lifecycle coverage.

IAM is a distinct, growing IT specialization (Entra ID, Okta, SailPoint, CyberArk). Dan's career-long IAM pattern is a strong signal for IAM Analyst/Engineer career paths — a specialization that leverages existing experience while offering higher compensation than generalist sysadmin.
