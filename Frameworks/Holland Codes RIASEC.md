# Holland Codes (RIASEC)

## Overview

Holland Codes, also known as the RIASEC model or Holland Occupational Themes,
is the most widely used and empirically validated framework for matching
personality to careers. Developed by John L. Holland, it classifies both PEOPLE
and WORK ENVIRONMENTS into six types. The closer the match between a person's
RIASEC code and their work environment, the higher the predicted job satisfaction
and performance.

**Applications in Anitalmid**: Holland Codes are THE career matching framework.
While Birkman provides the psychometric depth and Big Five provides the
scientific backbone, Holland Codes directly answer the question: "Which careers
match this person?" Every occupation in O*NET has a RIASEC profile, making this
the most ACTIONABLE framework for generating concrete career recommendations.

## The Six RIASEC Types

### R — Realistic (The Doers)

| Dimension | Description |
|---|---|
| **Core drive** | Working with things, tools, machines, and physical systems |
| **Values** | Practicality, results, tradition, hands-on competence |
| **Prefers** | Concrete problems, physical activity, outdoor work |
| **Avoids** | Abstract theory, social interaction, paperwork |
| **Best-fit careers** | Engineering, skilled trades, agriculture, law enforcement, military, field technician, construction |
| **Birkman interest alignment** | Technical (82%), Outdoor (40%) |
| **Big Five signature** | Low Openness, Low Extraversion, Low Agreeableness |
| **MBTI correlation** | ISTP, ESTP, ISTJ |

### I — Investigative (The Thinkers)

| Dimension | Description |
|---|---|
| **Core drive** | Understanding, analyzing, and solving problems through ideas |
| **Values** | Knowledge, precision, intellectual independence |
| **Prefers** | Research, analysis, theory, complex problem-solving |
| **Avoids** | Persuasion, routine, unstructured social situations |
| **Best-fit careers** | Scientist, researcher, software developer, systems analyst, data analyst, physician, security analyst |
| **Birkman interest alignment** | Scientific (92%), Technical (82%) |
| **Big Five signature** | High Openness, Low Extraversion, Low-Med Agreeableness |
| **MBTI correlation** | INTJ, INTP, ISTJ |

### A — Artistic (The Creators)

| Dimension | Description |
|---|---|
| **Core drive** | Creating, expressing, and innovating through unstructured media |
| **Values** | Creativity, originality, beauty, self-expression |
| **Prefers** | Writing, design, music, visual arts, performance |
| **Avoids** | Routine, rules, conformity, highly structured environments |
| **Best-fit careers** | Writer, designer, musician, artist, videographer, architect, UX designer, creative director |
| **Birkman interest alignment** | Artistic (94%), Musical (97%), Literary (92%) |
| **Big Five signature** | Very High Openness, Low Conscientiousness, High Neuroticism |
| **MBTI correlation** | INFP, ISFP, INFJ |

### S — Social (The Helpers)

| Dimension | Description |
|---|---|
| **Core drive** | Helping, teaching, counseling, and developing others |
| **Values** | Service, cooperation, empathy, social justice |
| **Prefers** | Teaching, counseling, mentoring, caregiving |
| **Avoids** | Isolated work, mechanical tasks, competitive environments |
| **Best-fit careers** | Teacher, counselor, social worker, nurse, HR, coach, clergy |
| **Birkman interest alignment** | Social Service (21%) — notably LOW for Dan |
| **Big Five signature** | High Extraversion, High Agreeableness, High Openness |
| **MBTI correlation** | ENFJ, ESFJ, INFJ |

### E — Enterprising (The Persuaders)

| Dimension | Description |
|---|---|
| **Core drive** | Leading, persuading, selling, and achieving organizational goals |
| **Values** | Success, status, power, financial reward |
| **Prefers** | Sales, management, politics, entrepreneurship |
| **Avoids** | Scientific research, routine, solitary work |
| **Best-fit careers** | Sales manager, executive, entrepreneur, lawyer, politician, real estate agent |
| **Birkman interest alignment** | Persuasive (32%) — notably LOW |
| **Big Five signature** | High Extraversion, Low Agreeableness, High Conscientiousness |
| **MBTI correlation** | ENTJ, ESTJ, ENTP |

### C — Conventional (The Organizers)

| Dimension | Description |
|---|---|
| **Core drive** | Organizing, managing data, and maintaining systems |
| **Values** | Accuracy, order, efficiency, reliability |
| **Prefers** | Data management, record-keeping, structured processes |
| **Avoids** | Ambiguity, unstructured creative work, confrontation |
| **Best-fit careers** | Accountant, administrative assistant, data entry, compliance officer, bookkeeper, auditor, records manager |
| **Birkman interest alignment** | Administrative (20%) — notably LOW |
| **Big Five signature** | High Conscientiousness, Low Openness, Low Extraversion |
| **MBTI correlation** | ISTJ, ISFJ, ESTJ |

## RIASEC Code Format

A person's Holland Code is typically expressed as a 2-3 letter combination
showing their dominant types in order:

- **Primary**: strongest interest area
- **Secondary**: second-strongest
- **Tertiary**: third-strongest (optional but common)

Example: `IAC` = Investigative-primary, Artistic-secondary, Conventional-tertiary

## The RIASEC Hexagon

The six types are arranged on a hexagon where adjacent types are most compatible
and opposite types are least compatible:

```
         REALISTIC (R)
              │
     CONVENTIONAL (C) ── INVESTIGATIVE (I)
         │                        │
    ENTERPRISING (E) ── ARTISTIC (A)
              │
         SOCIAL (S)
```

**Consistency**: Types closer together on the hexagon are more
psychologically consistent. An `IA` code (Investigative + Artistic) is
highly consistent. An `RE` code (Realistic + Enterprising) is moderately
inconsistent.

**Differentiation**: A "differentiated" profile has clear highs and lows
(strong preferences). An "undifferentiated" profile is flat across all types
(no strong preference) — harder to match to specific careers.

## Limitations for Career Matching

1. **Interest ≠ aptitude**: Holland Codes measure vocational INTEREST, not
   ability. Someone may be interested in a field they lack aptitude for.
2. **Static snapshot**: Career interests evolve with experience. A Holland
   Code at 22 may differ significantly at 42.
3. **Gender and cultural variation**: Research shows systematic differences
   in Holland Code distributions across gender and culture — these may reflect
   socialization rather than innate preference.
4. **Best used for**: Initial career EXPLORATION and screening, paired with
   aptitude assessment (like Birkman) and personality assessment (like Big Five)
   for a complete picture.

## Source and Authority

- **Origin**: John L. Holland, "Making Vocational Choices: A Theory of Vocational

- **Current applications**: O*NET (U.S. Department of Labor), Strong Interest
  Inventory, Self-Directed Search (SDS)
- **Peer-reviewed status**: VERY HIGH — decades of validation across cultures,
  educational levels, and career stages
- **Apt AI integration**: Apt uses Holland Codes as the primary career-matching
  engine, mapping user responses to RIASEC profiles and then matching against
  O*NET occupational data
