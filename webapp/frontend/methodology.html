The Anitalmid Method

Anitalmid triangulates three psychometric frameworks against the keywords in a resume, then scores the result against 150 career profiles across 24 fields to produce ranked, evidence-graded matches.

◆ Overview

The Anitalmid Project began as an Open Source Knowledge Graph (OSKG) — an Obsidian vault that turns a person's assessment data into atomic, falsifiable claims joined by typed edges (supports, contradicts, depends on, challenged by). The live web app generalizes that methodology: instead of a hand-built graph for one person, it reads a resume in real time, infers a personality + interest signature, and matches it against a field-agnostic role catalog.

resume → signal detection → role scoring → validation → ranked matches + career map

◆ The Three Frameworks

Anitalmid reads a resume for signals from three complementary frameworks: a type model (MBTI), a trait model (Big Five), and a vocational-interest model (Holland Codes). Using three independent lenses is deliberate — no single framework is authoritative on its own.

Myers-Briggs MBTI

Based on Jung's theory of psychological types, MBTI classifies people into 16 types across four dichotomies — a cognitive-style fingerprint for how someone processes information, decides, and organizes their world.

E / IExtraversion vs. Introversion — where you draw energy
S / NSensing vs. Intuition — how you take in information
T / FThinking vs. Feeling — how you make decisions
J / PJudging vs. Perceiving — how you organize your life

Big Five OCEAN

The academic gold standard. Personality measured on five continuous trait dimensions — the most empirically validated model in psychology, with the strongest predictive validity for career outcomes.

OOpenness — curiosity, creativity, appetite for ideas
CConscientiousness — order, discipline, follow-through
EExtraversion — sociability, energy, assertiveness
AAgreeableness — cooperation, warmth, trust
NNeuroticism — emotional stability under stress

Holland Codes RIASEC

The most widely used career-matching framework. Six vocational types classify both people and work environments; every occupation in O*NET carries a RIASEC code, making this the actionable layer that turns personality into concrete roles.

RRealistic — building, tools, machines, hands-on
IInvestigative — analyzing, researching, problem-solving
AArtistic — creating, writing, designing, expressing
SSocial — helping, teaching, counseling
EEnterprising — leading, persuading, selling
CConventional — organizing, data, systems

The RIASEC hexagon

Adjacent types are most compatible; opposite types are least. A code like IAR reads "Investigative-primary, Artistic-secondary, Realistic-tertiary."

◆ How the engine reads a resume

The pipeline is deterministic — no LLM guesses. It is keyword-driven signal detection plus weighted scoring against a curated role catalog.

  1. Parse the resume

    PDF (pymupdf) or plain text (.txt/.md/.rtf) is extracted into a single text blob.

  2. Detect the signal signature

    The text is scanned against field-spanning keyword lexicons — one per MBTI dichotomy, Holland type, and Big Five trait — using word-boundary prefix matching (so "collaborat" catches collaborate/collaboration/collaborative without false hits). Counts are tallied, and a type (MBTI), 3-letter code (Holland), and trait profile (Big Five) are inferred. Where there's no signal, the detector returns "unknown" rather than guessing.

  3. Score every role

    Each of the 150 role profiles is scored on two independent axes and blended:

    composite = 0.6 · keyword + 0.4 · framework + experience boost

    Keyword score — the role's own keywords are weighted strong ×3, moderate ×2, weak ×1, and contra-indicators −2, then normalized to 0–100. This measures experience — have you actually done this work?

    Framework score — 50% MBTI type match (share of known dichotomies) + 50% Holland code overlap. This measures aptitude — would you naturally fit this work?

    Experience boost — +10 for directly-experienced roles, +5 for low-barrier entry roles.

  4. Validate and rank

    Each match is tagged experience-validated (strong keyword evidence) or aptitude-validated (strong framework fit), then ranked. The top six become the match list and the nodes of the interactive career map.

◆ The Capstone

The engine's methodology descends from the project's capstone synthesis — a four-phase structural analysis of a person's assessment data modeled as a knowledge graph.

claims extraction → hinge inventory → cascade trees → counter-position tests → convergence analysis

In the original study, 32 atomic claims were extracted from a Birkman assessment and career history, joined by 136 typed edges, then stress-tested. The result was three settled convergences:

RoleSupportTimingPrimary action
Systems Administrator15 supporters (14 HIGH+)NowFormalize current role
Cloud Administrator (Azure)7 supporters (6 HIGH+)1–3 yearsAZ-900 → AZ-104 certification
Security Analyst6 supporters + Security+Evaluate nowBuild as secondary competency

The career arc the graph described — Systems Administrator → Cloud Administrator → Cloud/Security Architect — was not a career change but a career recognition with a clear progression path.

⚠️ The capstone was one person's personal synthesis. The live app keeps the method — signal detection, weighted scoring, and validation — but generalizes it to any resume across all fields, no Birkman assessment required.
